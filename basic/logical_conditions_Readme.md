# SQL Practice – Logical Conditions

## 📌 Objective

Practice SQL filtering using AND, OR conditions.

## 📊 Topics Covered

* Logical Operators (AND, OR)
* Filtering conditions
* Operator precedence

## 🧠 Problem Types

* Conditional filtering
* Multi-condition queries
* Real-world scenarios (HR, Orders, Flights)

## 🚀 Sample Problem

Retrieve employees:

* IT department with salary > 70000
* OR Active employees in HR

## 🛠 Tools Used

* SQL (MySQL/PostgreSQL compatible)
* GitHub for version control

## 📈 Learning Outcome

Improved understanding of:

* Writing precise WHERE conditions
* Avoiding logical mistakes in queries
